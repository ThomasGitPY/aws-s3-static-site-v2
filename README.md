# AWS S3 Static Website (V2)

This project is a rebuilt version of a static website hosted on AWS S3, created to reinforce cloud deployment concepts.

## What this project does

- Hosts a static website using AWS S3
- Uses an HTML file as the front-end
- Configures public access through bucket policies

## Key concepts learned

- S3 buckets and object storage
- Static website hosting
- Public access configuration and permissions
- Debugging access issues (403 errors)

## What makes this different (V2)

- Rebuilt entirely from scratch without step-by-step guidance
- Reinforces understanding of deployment flow and troubleshooting
